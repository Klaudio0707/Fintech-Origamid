📖 Sobre o Projeto
O Fintech Dashboard é uma interface web que permite aos usuários visualizar e analisar dados de transações financeiras. A aplicação consome uma API para buscar os dados e os apresenta de forma clara e organizada, com resumos, gráficos e uma lista detalhada de vendas.

Este projeto foi fundamental para solidificar conhecimentos em:

Componentização com React

Tipagem estática com TypeScript

Hooks do React (useState, useEffect, useContext)

Manipulação de APIs e estado global

Criação de gráficos interativos

✨ Funcionalidades
Resumo Financeiro: Cards com o total de vendas, valor recebido e em processamento.

Filtros Dinâmicos: Filtre as transações por período (mês ou data específica).

Gráficos de Vendas: Gráfico de linha que exibe a evolução das vendas ao longo do tempo.

Lista de Transações: Tabela com todas as vendas, exibindo detalhes como ID, nome, preço e status.

Design Responsivo: Interface adaptável para diferentes tamanhos de tela.

🚀 Como Executar o Projeto
Para rodar este projeto localmente, siga os passos abaixo.

Pré-requisitos
Node.js (versão 16 ou superior)

Git

Instalação
Clone o repositório:

Bash

git clone [[_GIT]](https://github.com/Klaudio0707/Fintech-Origamid)
Navegue até o diretório do projeto:

Bash

cd fintech-dashboard
Instale as dependências:

Bash

npm install
# ou
yarn install
Inicie o servidor de desenvolvimento:

Bash

npm run dev
# ou
yarn dev
Abra seu navegador e acesse http://localhost:5173 [(deploy)](https://fintech-origamid-omega.vercel.app/).
